# BIAI CRM — submission note

I built an enquiry workspace around BIAI’s supplied 20 messages. It keeps 19 contacts, preserves the full conversation, and provides the five requested pipeline stages with native drag-and-drop and 1-click advancement. The team can search, assign an owner, correct details, schedule follow-ups, resolve support cases, open direct WhatsApp chats with pre-filled drafts, and log completed contact. Reviewed fields and edited replies persist, and a separate practice workspace makes the workflow reproducible. Messages about payment confirmation and cancellation go to support; spam and a job application remain outside the sales queue.

AI works inside the intake flow: it reads a pasted message, extracts structured details, identifies the right queue and suggests a short reply in English, Bangla or Banglish. The user reviews the result before saving. I used AI tools to inspect the brief and data, develop the Node.js/SQLite application, draft prompts and tests, and investigate failures. The application supports Google Gemini, Meta Model API and OpenAI structured outputs, with intelligent offline NLP fallback for arbitrary custom messages. A separately labeled sample mode uses reviewed examples without claiming to call a live model.

I chose to leave ambiguous programmes and missing phones unresolved rather than invent details. Rafi’s repeated enquiry is one contact with two messages. A statement that someone paid never sets the stage to Paid. Replies request confirmation rather than promise undocumented prices, policies, locations or outcomes. Optional additions include 48-hour in-app reminders and a weekly brief.

The prototype does not send messages, verify payments, connect directly to social platforms or provide multi-user authentication. Reminders are in-app rather than background notifications. Next I would add authenticated team accounts, approved programme/policy knowledge for more specific replies, and human-reviewed channel integrations. The code includes automated checks and a reproducible live regression script; see the accompanying QA report for the validation actually performed.
